# Content Effect in LMs

To run experiment on Oscar (slurm)

1. clone this repo to your oscar directory

2. modify the REPO_PATH in `scripts/finetune.slurm` to the repo path with your oscar username

3. change directory with `cd scripts`

4. modify any training parameters in `finetune.slurm`

5. submit job with `sbatch finetune.slurm`
